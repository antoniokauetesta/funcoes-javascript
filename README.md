Atividades - Funções em JavaScript

Neste projeto foram criadas 10 pastas, cada uma contendo seu respectivo código JavaScript e a função solicitada na atividade.

Cada pasta representa uma questão, com seu código separado e organizado para facilitar a compreensão e a execução.

As atividades trabalham conceitos como funções, parâmetros, retornos, cálculos, condições e operações matemáticas.
